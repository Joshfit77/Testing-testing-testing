# Beauty and Praise 🌿

A website about herbs and healthy reminders.

## Features
- **Herb Garden** – searchable, filterable cards for common herbs with uses and cautions
- **Healthy Reminders** – rotating wellness tips
- **Daily checklist** – tick off habits, add your own; resets each day (saved in your browser)
- **Water tracker** – tap to log glasses of water
- **Verse of the day** in the header

## Run it
No build step needed — just open `index.html` in a browser.

## Edit content
All herbs, reminders, default habits and verses live in `data.js`.

## Files
- `index.html` – page structure
- `styles.css` – styling (includes dark mode and mobile layout)
- `script.js` – interactivity
- `data.js` – content
