# Narrow Gate Fitness: final trademark and brand review

**This is research, not legal advice, and it does not clear any name.** These notes record what public records and web sources showed on 2026-10-26. Only a trademark attorney's full search (USPTO, state registers, common law, design and phonetic variants) followed by a legal opinion can clear a name. Common-law rights come from use alone, so a business with no registration can still hold rights in its trading area.

**Scope:** NARROW GATE FITNESS and its variants, FAITH & DISCIPLINE, NUTRITION SCORE, NUTRI-SCORE, FOOD IQ, and the most distinctive names in the app. The names were inventoried from `src/app`, `src/components`, `src/lib/domain/{program-catalog,ranks,challenge,achievements}.ts`, `src/data/programs.ts`, `src/lib/food-iq.ts` and `docs/OPENING.md` on branch `claude/free-pro-membership`. Nothing in the repository was edited.

**How the research was done, and its limits (read this first):**
- Every official register and every direct page fetch was blocked in this sandbox. The proxy refused CONNECT with a 403, and WebFetch failed DNS lookup. The blocked sites were tsdr.uspto.gov, tsdrapi.uspto.gov, tmsearch.uspto.gov, uspto.gov, rdap.org, trademarks.justia.com, uspto.report and the business websites. WIPO Global Brand Database, EUIPO eSearch, Apple App Store search and Google Play search were also not reachable as live searches.
- So every fact below comes from **web-search results** (search-engine summaries of mirror pages such as Justia and TrademarkElite, of the businesses' own sites and of store listings). Each such fact is marked **(mirror)** or **(web)**.
- **No status in this file is TSDR-verified.** Each one has to be confirmed on TSDR before anyone relies on it.
- I checked the earlier audit (`docs/launch-audit/C_TRADEMARKS.md`, 2025-10-25) against these sources. Where I could not reconfirm one of its facts, this file says so.

## 4. Recommendations (research, for the owner and counsel)

1. **Keep "Narrow Gate Fitness."**
   - No conflict serious enough to justify a rename surfaced: no live NARROW GATE registration in the relevant classes, and no app with the same name.
   - Keeping or changing the name is the owner's decision with counsel. The open questions are the local senior users (PA gym, NC club) and the pending NARROW PATH ATHLETICS application.
2. **File for NARROW GATE FITNESS once counsel's knockout and full search come back clean enough.**
   - **Classes:**
     - **9** (downloadable mobile fitness, nutrition-tracking and devotional software)
     - **41** (fitness instruction and online non-downloadable fitness, training and devotional content)
     - **42** (non-downloadable software / SaaS for tracking workouts and nutrition), as counsel advises
     - **44** only if the nutrition guidance is marketed as dietary or nutrition information services
     - **25** only if merchandise is planned
   - Counsel may advise disclaiming "FITNESS". Counsel may also consider a separate NARROW GATE filing, which is stronger but more exposed to the crowding above.
   - **Basis:** probably **1(b) intent-to-use** for now. The app has no public paid availability, and internal TestFlight builds, APKs and a public GitHub PR are not clearly "use in commerce". Switch to **1(a)** only if counsel confirms bona fide use in commerce at filing, with specimens. Filing 1(b) early fixes a constructive-use priority date. The repository's public PR shows the name in the open, which is another reason to file soon.
   - **USPTO fees** (from secondary summaries of the FY2025 final rule, 89 FR 91062, effective 2025-01-18):

     | Fee | Amount |
     |---|---|
     | Base application (Trademark Center) | **$350 per class** |
     | Insufficient-information surcharge | +$100 per class |

     | Each extra 1,000 characters | +$200 per class |
     | Amendment to Allege Use / Statement of Use | $150 per class |
     | SOU extension | $125 per class, per 6-month extension |

     | Section 9 | $325 per class |

     - **Example:** classes 9 + 41 + 42 on a 1(b) basis using ID Manual entries cost about $1,050 to file plus $450 for the SOU, about $1,500 in USPTO fees before any extensions or attorney fees.
