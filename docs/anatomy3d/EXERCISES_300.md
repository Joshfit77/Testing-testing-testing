# From 157 to 300 exercises: proposed additions (awaiting approval)

The app has **157 exercises**, each with a hand-made motion. The 3D model now performs all of them, and
`scripts/anatomy/preview/render-videos.mjs` renders a video of each.

Reaching **300** means adding **143 exercises** to the library. That is new content for the app, so this is a proposal
for approval: nothing below is in the app yet.

Each new exercise needs:
- an entry (instructions, cues, mistakes, muscles);
- a hand-made motion.

Most of the motions are variants of an existing one (marked "from …"), which is quicker and keeps the same reviewed
mechanics. None of the names duplicates an existing exercise.
