# Pro program catalog (40 programs)

Branch `claude/pro-premium`, 2026-11-13. Nothing here is merged, deployed or live.

## Status in one paragraph

All 40 catalog entries exist in the app. 32 are structured training programs (22 new, 10 existing ones adopted with
their prescriptions unchanged), 7 are new habit programs (nutrition, faith and fitness, a 90-day journey) and #37 is the
existing 40-day discipline challenge, left exactly as it was. Every structured program is Pro for new enrollments; Free
members keep manual logging, their own workouts and templates, and the personal starter plan built at onboarding.
**No program has been reviewed by a certified coach, physiotherapist or registered dietitian.** All are marked
unverified below; the automated checks only prove structure (week counts, real exercise ids, progression, deloads,
session length), not that the programming is right for any individual.

## What every training program contains (and how it is checked)

| Requirement | Where | Checked by |
|---|---|---|
| Name, description, goal, level, duration, schedule, equipment | `ProgramSeed` fields | `tests/unit/program-library.test.ts`, `program-catalog.test.ts` |
| Day-by-day plan with library exercise ids, sets, reps or time, rest, RPE or intensity | `weekTemplates` → `expandProgram` | every exercise slug must exist in `EXERCISE_SLUGS`; sane prescriptions |
| Real week-to-week progression, planned deloads | `weekTemplates`, `progression` | week 1 and the last loading week must differ; deload or stated reason |
| Warm-up and cool-down | `warmup`, `cooldown`, per-day lists | non-empty |
| Rest days | days per week, spacing in instructions | schedule length |
| Substitutions | exercise alternatives (library) and Swap in the logger | every alternative id exists |
| Weekly milestones | `milestones` (one per week) | `milestones.length === weeks` in each batch test |
| Instructions (choosing loads by effort, missed sessions, when to stop) | `instructions` | 3–6 per program |
| Completion criteria | `completionRequirement` or `completion` | shown on the program page |
| Tracking | workouts log against the program run; progress on the program page | integration tests |

Starting loads are never prescribed: every program says to choose weights by RPE or reps in reserve. Missed sessions
never restart a program; the instruction is to carry on, and repeat a week if two or more sessions were missed.

## Habit programs (33–36, 38–40)

Daily and weekly activities instead of sets and reps (`src/data/habit-programs/`, migration 064). Members tick
activities for today or earlier days (never future days), adjust their own goals (protein, water, steps and so on), and a
logged workout or food entry counts automatically. Missing a day never resets anything. Nutrition programs avoid
restrictive diets: they use the app's own calorie target (a moderate deficit or small surplus) and tell members not to
go lower on their own, and no food or food group is banned. They are flagged **for registered-dietitian
review before release** (33, 34, 35, 36 and 40). Faith activities in 38 and 39 are optional, use the app's existing
Bible translation and keep journal entries private (they are never sent to the AI coach); physical performance is never
presented as a measure of spiritual standing. No strict restart rule applies to any new program.

## Access rules

* New enrollment in any library program or habit program: Pro (`full_program_library`), enforced in the server actions
  and in the database (`can_use_program`, habit-program RLS).
* A member already enrolled in, or who saved, a library program before this change keeps it, including after Pro ends
  (migration 065). Tested: a Free member cannot create that earlier-enrollment row themselves.
* Switching programs pauses the current run; completed workouts keep their program and day links.
* Records stay readable (and exportable, deletable) after Pro ends.

## AI coach

`get_program_recommendations` ranks programs from the member's onboarding answers (goal, experience, equipment, days per
week, session length, preferred training) and lists the habit programs with their review flags; the coach adds
history, limitations and recovery from its consented context and memory. `propose_program` only shows a card: nothing
starts until the member taps Start, the server re-checks access, and the current program is paused, never deleted.

## Decisions for the owner

1. **#26 Aerobic Endurance Builder.** Mapped to the existing "First 5K: Run/Walk to 30 Minutes" (8 weeks, 3 days),
   which overlaps #22 (new 10-week run/walk to 5K). A dedicated 8-week, 3–5 day aerobic base program for people who
   already run would match the brief better. Recommend: build it as a new program and keep the existing one as an
   extra; say if you want that.
2. **Professional review.** Before release, a qualified strength coach should review 1–32, a physiotherapist 21 and
   29–32 (and anything aimed at older adults), and a registered dietitian 33–36 and 40.
3. **Faith & Fitness programs as Pro.** The brief makes 38–40 Pro; the existing rule that the Faith section is always
   free is unchanged (#37, Scripture, devotionals, journal and journeys stay free).
