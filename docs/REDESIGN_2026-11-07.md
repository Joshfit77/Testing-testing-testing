# Visual redesign from the owner's 10-screen reference (2026-11-07)

The owner supplied a 10-page PDF, one iPhone screen per page, as the visual direction for Narrow Gate Fitness. Each page
is marked "Visual reference only. Implement working interfaces using original or licensed assets." This pass restyles the
ten corresponding screens of the real, working app to that direction without changing what the app does: every feature,
data flow, security check, 2D exercise animation and subscription rule is unchanged. Nothing was merged to main, deployed,
or connected to real payments.

Side-by-side sheets (reference page on the left, the real app on the right, captured on the demo account at iPhone 15 Pro
size, 393 × 852 at 2×) are in `docs/screenshots/redesign-2026-11-07/`.

## Shared design language (built once, used by all ten screens)

| Element | Implementation |
| --- | --- |
| Gold-outlined cards | `.card-gold` and `.card-gold-strong` utilities in `src/app/globals.css` (gradient border, warm charcoal fill, soft gold glow). |
| Round gold play / send buttons | `.btn-gold-round` utility; `TodayWorkoutAction round`, the coach composer send button. |
| Pill switches (period, category, Setup/Execution/Mistakes, Bible/Prayer/Plans) | `src/components/ui/segmented.tsx` (`Segmented`): links get `aria-current`, button tabs get `role="tab"`. |
| Icon + label + big value tiles | `src/components/ui/stat-tile.tsx` (`StatTile`). |
| Scenic hero with cross and sunrise | `src/components/common/scene-hero.tsx` over a new original vector scene `public/illustrations/sunrise-cross.svg` (drawn for this app; no stock photography). |
| Tab bar | Outlined icons, active tab gold, Faith tab now a cross icon, Train tab a flexed-arm icon (`src/components/shell/nav-config.ts`, `app-shell.tsx`). |

## What was deliberately not done

- No stock photography, no competitor assets: the imagery is the app's own vector scenes.
- No change to tab labels, pricing, subscription logic, entitlements, data model or server code (one read-only addition: the workout page now also loads each exercise's written `instructions` for the Setup tab).
- No invented metrics (muscle mass, "+2.5%" progress) and no fixed verses: every number and verse on screen comes from the member's data or the app's existing content.
- The demo warning notices stay in place.

## Verification

- `tsc --noEmit`: clean. `eslint` on the changed directories: clean.
- Unit suite (`vitest run`): 3,566 passed, 1 skipped, 2 failed on first run (both in the billing-period test that looked for a "Yearly" radio; after accepting "Annual" the file passes 11/11).
- Full Playwright e2e suite against the final production build (`next build` + `next start`, mocked AI and food APIs): 118 passed, 0 failed, 59 skipped (the skipped ones are the demo-mode and desktop-only cases, as in every earlier run). The demo-mode suite (`e2e/demo.spec.ts` with `E2E_DEMO=1` against the demo server built from the same commit): 17 of 17 passed.
- The first full run found six failures: two were the Home verse link losing its "Verse of the day" name, two were the fast-logging helper reading the ring's "Rest" label instead of the time, and two (memberships) predate this work: the accessibility commit of 2026-11-06 changed the rank buttons' names and updated `rank-badges.spec` but not `memberships.spec`. All six are fixed in the follow-up commit; the memberships spec now uses the same regex form as `rank-badges.spec`.
- Tests updated for the new look: Home greeting (`Good morning|afternoon|evening, …` instead of `Hi, …`), rest adjustment buttons (±30 s, and the rest-over loop stops at 35 s), billing-period radio name (`Yearly|Annual`).
- Each of the ten screens was captured from the running app and placed next to its PDF page in `docs/screenshots/redesign-2026-11-07/`.

## Owner decisions (one-line changes if wanted)

1. Tab labels: keep Home / Train / Nutrition / Faith / You, or switch to the reference's Training / More.
2. Greeting: the member's first name, or a fixed "Brother"/"Sister" by profile.
3. Program card imagery: keep the vector scenes, or supply licensed photographs per category.
